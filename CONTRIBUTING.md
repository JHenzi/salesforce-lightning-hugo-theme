# Contributing to Salesforce Lighting Theme

Thank you for your interest in contributing to the Salesforce Lighting Hugo theme!

## How to Contribute

### Reporting Bugs

If you find a bug, please open an issue with:
- A clear description of the bug
- Steps to reproduce
- Expected vs actual behavior
- Your Hugo version
- Browser/OS information if relevant

### Suggesting Features

Feature suggestions are welcome! Please open an issue with:
- A clear description of the feature
- Why it would be useful
- Any examples or mockups if applicable

### Submitting Pull Requests

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/your-feature-name`)
3. Make your changes
4. Test your changes thoroughly
5. Commit with clear messages (`git commit -m 'Add feature: description'`)
6. Push to your fork (`git push origin feature/your-feature-name`)
7. Open a Pull Request

### Code Style

- Follow existing code style and conventions
- Keep HTML semantic and accessible
- Use SLDS classes and components where possible
- Add comments for complex logic
- Test on multiple browsers/devices

### Testing

Before submitting:
- Test on different screen sizes
- Verify accessibility
- Check browser compatibility
- Ensure Hugo builds without errors

Thank you for contributing! 🎉
