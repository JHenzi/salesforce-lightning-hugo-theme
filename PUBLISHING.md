# Publishing Checklist

Before publishing this theme to GitHub, make sure to:

## Required Changes

- [x] Update `theme.toml`:
  - [x] Replace `YOUR_USERNAME` with your GitHub username
  - [x] Update author name and homepage
  - [x] Update license link to point to your repo

- [x] Update `README.md`:
  - [x] Replace all `YOUR_USERNAME` placeholders
  - [x] Add actual theme preview screenshot
  - [x] Update author information
  - [x] Add any additional documentation

- [x] Update `LICENSE`:
  - [x] Replace "Your Name" with your name
  - [x] Update year if needed

- [ ] Review all files:
  - [ ] Remove any site-specific content
  - [ ] Ensure no hardcoded URLs point to your site
  - [ ] Check for any personal information

## Optional Enhancements

- [ ] Add `exampleSite/` folder with example content
- [ ] Add screenshots to README
- [ ] Create GitHub Actions for testing
- [ ] Add version tags
- [ ] Create a demo site
- [ ] Submit to Hugo Themes directory

## Files to Review

- `theme.toml` - Theme metadata
- `README.md` - Documentation
- `LICENSE` - License file
- `CONTRIBUTING.md` - Contribution guidelines
- All template files for site-specific content

## After Publishing

- [ ] Submit to [Hugo Themes](https://themes.gohugo.io/)
- [ ] Share on social media
- [ ] Update your website with a link to the theme
- [ ] Consider adding a demo site
